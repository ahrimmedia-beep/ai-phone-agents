# AI phone agents

Voice agents that answer and make phone calls. They speak naturally, qualify the client and pass the result to the CRM.

## What it does

- The inbound agent answers calls 24/7, answers questions and books a viewing or a callback.
- The outbound agent calls a warm base and finds clients who are ready to talk to a manager.
- Both handle interruptions and pauses like a person.
- After each call the transcript turns into a structured lead in Telegram, Google Sheets and the CRM.

## Stack

Voximplant VoxEngine (JavaScript), OpenAI Realtime API, function calling, n8n webhooks.
